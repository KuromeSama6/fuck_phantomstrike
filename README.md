# Overview

This program does three simple things:

1. It opens the *Deadlock* log file for reading (with the `-condebug` and `+snd_showstart 1` option);
2. It waits until it sees the line `sounds\mods\armor\phantom_strike\phantom_strike_cast_01.vsnd`.
3. When it sees that line, it will send a parry key press to the game window.

# Usage

1. Launch *Deadlock* with the `-condebug` and `+snd_showstart 1` options.
2. Launch this program.

## Notes on Parrying Phantom Strikes

- The startup for Phantom Strike (the time before its cast to the time it hits you) is roughly the same as an average human's reaction time. Given that you will be focusing in other things in the game, reaction parrys are highly unlikely.
- You should instead learn to read when a phantom strike is coming. If they have phantom strike and they are staring at you and running at you full speed, they are likely going to phantom strike you. Get ready to parry.
- Unstop should be used like counterspell. Think of it as a parry with an extra long window.
